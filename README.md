# Social Hub

Social Hub is a modern monorepo designed to house applications and shared packages for the Social Hub platform.

## Tech Stack

- Next.js
- NestJS
- PostgreSQL
- Prisma
- Docker
- pnpm Workspace

## Project Structure

- `apps/`: Main applications (e.g., frontend web application, backend API service).
- `packages/`: Shared libraries and configurations (e.g., UI component library, shared utilities/types, configuration packages).
- `infrastructure/`: Infrastructure configurations, container setups (e.g., Docker), and deployment configurations.
- `docs/`: Project documentation, architectural decisions, and guides.
